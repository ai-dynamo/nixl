| Variable | Type | Default | Description |
|----------|------|---------|-------------|
| `NIXL_MOONCAKE_IP_ADDR` | String (IP) | First non-loopback interface IP | Override IP address for the Mooncake transport engine. Set this when auto-detection selects the wrong network interface. |
| `NIXL_MOONCAKE_NUM_THREADS` | Integer | `0` | Threads that submit large transfers in the background: `postXfer` queues the transfer as one Transfer Engine batch per thread and returns, and `checkXfer` reports it in progress until every batch is submitted. `0` submits every transfer from the calling thread. The `num_threads` backend parameter, which Python's `nixl_agent_config(num_threads=...)` sets, takes precedence. At most four threads per hardware thread. Ignored, with a warning, on a Transfer Engine without `getBatchTransferStatus()` (Mooncake before v0.3.14). Each engine also runs one thread that frees finished transfers, whatever this is set to. |
| `NIXL_MOONCAKE_SPLIT_BATCH_SIZE` | Integer | `1024` | Smallest transfer, in descriptors, that `NIXL_MOONCAKE_NUM_THREADS` submits in the background. The `split_batch_size` backend parameter takes precedence. |
